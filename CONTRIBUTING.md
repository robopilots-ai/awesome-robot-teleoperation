# Contributing

Suggestions are welcome, including entries for companies that compete with the maintainer. Open a pull request or an issue.

## What belongs here

- Tools, hardware, datasets, papers, platforms, services and job boards that are directly useful for teleoperating robots or for collecting robot-learning data by teleoperation.
- Projects that are public and maintained, or papers and datasets that are still widely used.

## How to add an entry

- Use the format `- [Name](link) - Short description.` Start the description with a capital letter and end it with a period.
- Write one neutral, factual line. Describe what it does, not how good it is. No marketing words, rankings, customer names or unverifiable numbers.
- Link to the project's own page or repository. For papers, link the arXiv abstract page (`https://arxiv.org/abs/...`), not the PDF.
- Put code, paper and docs links in brackets inside the description when a project has more than one: `([code](...), [paper](...))`.
- Add the entry to the end of the most fitting section. Services are kept in alphabetical order.
- Check that every link loads.
- No affiliate or tracking links.

## Disclosure

If you work for or are paid by the project you add, say so in the pull request description.

## Removals

Entries whose links stop working, or whose projects are archived and superseded, may be removed. If an entry about your company is out of date, open an issue with the correction and a link to your own page that shows it.
